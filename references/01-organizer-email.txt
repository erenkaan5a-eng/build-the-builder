Your Freya API key:
Sign in at [https://staging-app.freyavoice.ai](https://staging-app.freyavoice.ai) and create a key in your workspace under API keys. Put it in env.sh as FREYA_API_KEY.
The bank's tool API:
The phone agent calls it during a call. Its description is in the kit at tools/openapi.json. You pick your own team key, any secret of 16 or more characters, and use the same one every time.
Starter workflow:
Your workspace already has "Freya Bank Collections Base". Its test variables hold a practice customer, so you can start a chat right away. The same agent is in the kit as examples/base-agent.json.
